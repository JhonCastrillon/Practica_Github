Bienvenido al repositorio oficial de la exposición sobre Git y GitHub. Este proyecto es una plantilla interactiva diseñada para aprender el flujo de trabajo colaborativo en tiempo real.

---

## 🛠️ ¿Qué estamos aprendiendo?
En esta sesión exploraremos el ciclo de vida de un cambio en Git:
1. Modificación (Working Directory)
2. Preparación (git add)
3. Confirmación (git commit)
4. Sincronización (git push)

---

## 👥 Dinámica de la Actividad

### 🔴 Grupo A: Colaboradores Directos
Objetivo: Experimentar el trabajo en equipo sobre una misma rama.

1. Clona el repositorio:
git clone https://github.com/JhonCastrillon/Practica_Github.git

2. Edita el archivo index.html:
Busca la sección de "Colaboradores" y añade tu nombre.

3. Sube tus cambios:
git add .
git commit -m "Agregando mi nombre a la lista"
git push origin Main

Nota: Si recibes un error de rechazo, ejecuta primero "git pull origin Main".

---

### 🔵 Grupo B: Externos (Fork & Pull Request)
Objetivo: Contribuir a proyectos externos (Estilo Open Source).

1. Haz un Fork:
Haz clic en el botón Fork (arriba a la derecha en GitHub).

2. Modifica el diseño:
Edita el archivo style.css en tu copia. Cambia colores o estilos.

3. Envía un Pull Request:
Desde tu fork, solicita integrar tus cambios al repo original.

---

## ⚡ Comandos de Supervivencia

- git status: Muestra archivos modificados pendientes de subir.
- git pull origin Main: Descarga los últimos cambios del equipo.
- git log --oneline: Muestra el historial de cambios resumido.
